# Autonomous-vehicle-safety-self-anylysis
Analysed 2,500 autonomous vehicle journeys using Python, Pandas and data visualisation techniques.
Cleaned, merged and explored multiple datasets to investigate relationships between weather, traffic, sensor confidence and vehicle performance.
Developed and evaluated a Logistic Regression classification model to predict journey problems using performance metrics including accuracy, precision and recall.
Presented data-driven findings, model limitations and recommendations considering AI safety, bias and ethical implications.
